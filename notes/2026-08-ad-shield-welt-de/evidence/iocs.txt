## Serving pattern — more durable than any single domain
# Each primary host serves the same two files:
#     /vendor.js   and   /main.js
# Each has a matching "fb." subdomain serving:
#     /app.js
# The domains are interchangeable and rotate. fuel.norexceptdrug.com is a
# nonsense-word host with exactly one urlscan submission ever (2026-08-05) and
# the same file layout as html-load.com — i.e. freshly rotated infrastructure.
# Matching on the pattern catches successors that a domain list will miss.

## URL patterns — two distinct endpoints
# 1) Scareware modal shown to the user:
#    report.error-report.com/modal?url=<b64>&error=<b64>&domain=html-load.com
#
# 2) Silent telemetry callback, seen in the DevTools console
#    (screenshot 03) — different host (apex, not report.) and different
#    parameters, notably a request_id:
#    error-report.com/report?type=loader_light&url=<b64>&error=<b64>&request_id=<b64>
#    The value "loader_light" matches the "level: light" field in the
#    injected marker below — the integration tier is reported back.
